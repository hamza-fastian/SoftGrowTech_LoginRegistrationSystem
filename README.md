# SoftGrowTech_LoginRegistrationSystem
📌 Description

This project is a Login and Registration System developed in C++ that handles user authentication with proper validation. It allows users to register with unique usernames and secure passwords, and login using stored credentials.

The system uses file handling to store user data persistently and ensures data validation for security and accuracy. It demonstrates core programming concepts including file handling, input validation, and basic authentication system design in C++.

Additionally, the system includes password strength checks and duplicate username prevention to enhance reliability. It follows a menu-driven approach for better user interaction and simplicity. This project helped strengthen understanding of file operations and real-world authentication logic.
